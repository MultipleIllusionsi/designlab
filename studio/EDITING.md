# Как добавлять и редактировать карточки галереи

Инструкция для редакторов. Код трогать не нужно — всё делается в двух веб-инструментах.

## Как это устроено

- **ImageKit** (аккаунт `ivitest` → папка `ivi_design_lab`) — хранит сами файлы.
- **Sanity Studio** (`*.sanity.studio`) — каталог: какая карточка, в каком порядке, с каким
  заголовком/описанием/тегами и на какой файл ссылается.

Файл лежит в ImageKit, а карточка в Sanity ссылается на него **по имени**.
Поэтому добавление медиа — это два шага.

---

## Добавить новое медиа

### Шаг 1 — загрузить файл в ImageKit
1. Зайди в ImageKit (общий аккаунт) → **Media Library** → папка **`ivi_design_lab`**.
2. Загрузи картинку или видео **в эту папку**.
3. Правила по имени файла (важно!):
   - **без пробелов**, **строчными буквами** — например `my_new_video.mp4`, а не `My New Video.mp4`
     (регистр важен: `Foo.mp4` и `foo.mp4` — разные файлы);
   - обязательно с расширением (`.mp4`, `.png`, `.jpg`);
   - имя уникальное и понятное;
   - после того как файл привязан к карточке — **не переименовывай и не удаляй** его.

### Шаг 2 — создать карточку в Sanity Studio
1. Открой Studio → раздел **Media items** → **Create**.
2. Заполни поля:
   - **Media** — вставь **точное имя файла** из ImageKit (например `my_new_video.mp4`).
     Поле само определит тип (картинка/видео), размеры и покажет **превью**.
     ⚠️ **Дождись превью.** Если появилось превью и бейджи «Video/Image» + размеры — файл
     привязан правильно. Если «not found» — имя не совпадает или файл ещё не долился.
   - **Title** — заголовок.
   - **Description** — описание (необязательно).
   - **Alt text** — короткое описание для доступности (особенно для картинок).
   - **Tags** — выбери `interface` / `motion` / `graphic` (по ним работает фильтр на сайте).
3. Нажми **Publish**.
4. Через несколько секунд карточка появится на сайте — **без пересборки/деплоя**.

---

## Поменять порядок карточек

В списке **Media items** просто **перетащи** карточку мышью на нужное место.
Порядок сохраняется сразу, **публиковать не нужно** — на сайте обновится через несколько секунд.

## Изменить или удалить карточку

- **Изменить:** открой карточку → поправь поля → **Publish**.
- **Удалить:** удали документ в Studio. Файл при этом останется в ImageKit
  (при желании удали его и там — но только если на него не ссылается другая карточка).

---

## Важные правила (частые ошибки)

| Правило | Почему |
|---|---|
| Имя файла в ImageKit и в поле **Media** — **строго одинаковое** (регистр важен) | Иначе карточка не найдёт файл |
| **Дождись превью** в поле Media перед Publish | Гарантия, что файл привязан и тип определён верно |
| Правки контента → **Publish**; порядок → **перетаскивание** | Разные механики: контент публикуется, порядок живой |
| Не переименовывай и не удаляй в ImageKit файлы, на которые есть карточки | Сломает эти карточки на сайте |

## Про видео

Ничего вручную готовить не нужно. В сетке на главной автоматически показывается лёгкое
**3-секундное превью**, а на детальной странице — полный оригинал. Просто загрузи обычный
видеофайл и создай карточку, как описано выше.

## Если карточка не грузится

1. Открой её в Studio и проверь поле **Media** — есть ли превью? Если «not found» —
   имя файла не совпадает с тем, что в ImageKit (проверь регистр и расширение).
2. Убедись, что файл действительно лежит в ImageKit в папке `ivi_design_lab`.
3. После исправления нажми **Publish** и обнови сайт через несколько секунд.
