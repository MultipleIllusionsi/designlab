# Как добавлять и редактировать карточки галереи

Всё делается в **Sanity Studio** — файлы загружаются прямо туда. Код и другие сервисы трогать не нужно.

## Как это устроено

- И каталог, и медиа (картинки, видео) живут в Sanity. Редактор работает только в Studio.
- Сайт читает данные из Sanity: картинки оптимизируются на лету, видео и превью отдаются с CDN.
- Новая карточка появляется на сайте **через несколько секунд после публикации**, без пересборки.

---

## Добавить карточку

1. Studio → **Media items** → **Create**.
2. Выбери **Тип медиа**: **Изображение**, **Видео** или **Vimeo** — форма покажет нужные поля.
3. Заполни медиа:
   - **Изображение** — загрузи картинку прямо в поле.
   - **Видео** — загрузи видеофайл. Лёгкое превью для главной **создастся автоматически** (в течение нескольких часов). Пока его нет — в сетке показывается полный ролик, ничего не сломано.
   - **Vimeo** — два поля:
     - **Ссылка на Vimeo** — на детальной странице встроится плеер.
     - **Изображение для главной** — постер, который показывается в сетке.
4. **Описание** — показывается на детальной странице. Поддерживает **ссылки**: выдели текст → на панели редактора нажми **«Ссылка»** → вставь URL. На сайте ссылки кликабельны и открываются в новой вкладке. Есть также жирный/курсив.
5. **Теги** — `interface` / `motion` / `graphic` (по ним работает фильтр на главной).
6. Нажми **Publish**.
7. Через несколько секунд карточка появится на сайте.

## Поменять порядок карточек

Перетаскивай карточки мышью в списке **Media items** — порядок сохраняется сразу, **публиковать не нужно**.

## Изменить или удалить карточку

- **Изменить:** открой карточку → поправь поля → **Publish**.
- **Удалить:** удали документ в Studio.

---

## Про видео

Просто загрузи **один** видеофайл — больше ничего не требуется. Превью для сетки сделается само. Тяжёлые ролики можно предварительно сжать, но это не обязательно.

## Про Vimeo

Для vimeo-карточки нужно **и то, и другое**: ссылка (для плеера на детальной) и изображение (постер для сетки).

## Частые ошибки

| Симптом | Что проверить |
|---|---|
| Карточка не сохраняется (ошибка валидации) | Загружено ли медиа под выбранный тип (изображение / видео / ссылка+постер для vimeo) |
| Файл «не догрузился» | Дождись окончания загрузки в поле перед **Publish** |
| Ссылка в описании не кликается на сайте | Ссылка добавляется кнопкой «Ссылка» в редакторе описания (не просто текстом) |
